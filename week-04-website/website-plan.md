# Website Plan

## Website subject

My website is about gaming and provides information about games and gaming activities.

## Purpose

The purpose of the website is to provide information about gaming, different games and activities. It will also give users a simple and enjoyable way to explore the website and find useful information.

## Target users

The website is aimed at people who are interested in games and gaming activities, especially teenagers and young adults.

## Required pages

| Page | Filename | Planned content |
|---|---|---|
| Home | index.html | Introduction to the website and general information about gaming |
| About | about.html | Information about the website and its purpose |
| Activities | activities.html | Information about different gaming activities and things users can do |
| Contact | contact.html | Contact information and a contact form |

## Shared content

The content that will appear on every page includes:

- Navigation menu
- Website logo/name
- Footer
- Links to the main pages

## Colour ideas

I may use:

- Dark blue
- Purple
- White

These colours will give the website a modern gaming style.

## Website structure

Users will move between the pages using the main navigation menu. The navigation menu will be available on every page, so users can easily go to the Home, About, Activities or Contact page.
