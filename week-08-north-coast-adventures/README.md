# North Coast Adventures — Week 8 Starter Project

This project contains the completed HTML and written content for two responsive pages:

- `index.html` — the Flexbox homepage practical.
- `contact.html` — the Grid, form, icons and map practical.

Complete the guided sections inside `css/style.css`. Begin with the mobile layout and use `min-width` media queries to enhance the layout when more space is available.

The files inside `images/` are temporary placeholders. Your lecturer may replace them with the final project images using the same filenames.

The enquiry form is for layout practice and is not connected to a server.
