# Week 6 CSS Layout Examples

This starter project contains four separate HTML layouts.

## Completed examples

- `index` uses `css/landing.css`
- `products.html` uses `css/products.css`
- `contact.html` uses `css/contact.css`

## Independent task

- `student-layout.html` contains the complete HTML structure but no stylesheet.
- Students should create `css/student-layout.css` and connect it to the page.

All supplied HTML and CSS is commented to help identify the purpose of each section and rule.
